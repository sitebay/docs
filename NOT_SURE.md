# Verification boundaries

The complete documentation refresh covers all 348 Markdown sources, including
navigation and reusable fragments. The former editorial baseline allowance is
removed. Source review, strict editorial checks, spelling, build, links,
reference generation, and browser behavior are checked separately.

## What source review establishes

Product instructions were checked against the owning SiteBay, Sorti, editor,
analytics, theme, and integration source. External topics use primary provider
documentation. Each article has a source basis and a review record under `ci/`.
These records identify the reviewed source; they do not claim that every
customer account or deployed environment exposes every source-level capability.

## What was not executed

No production deployment, release, customer migration, security scan, plugin
update, billing change, or Algolia administration write was performed. Browser
checks use the built site with remote services replaced by fixtures. Native
hardware, app-store releases, and third-party credentials were not exercised.
The STS2 source workflow is not official-art or live-game acceptance.

## Time-sensitive and historical material

Offers, service limits, model availability, and eligibility are linked to their
current authoritative catalogs instead of copied into a fixed promise. The
retained videos and RoiD1kan case-study images are explicitly historical; they
were not captured again during this refresh. A generated API catalog is a
selected source-derived reference, not a live endpoint test.

## Source and release custody

Private source bytes remain outside this documentation repository. Public
review metadata contains paths, hashes, and relevant source URLs only. The
rollback on `main` remains separate from the completed refresh branch; merging
or releasing the candidate requires an explicit acceptance action.
