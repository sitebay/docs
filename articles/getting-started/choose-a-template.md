# Choose A Template

Pick the template that matches how the site will be managed.

## Use WordPress When

- You need pages, posts, plugins, menus, or WordPress admin workflows.
- You want SiteBay’s WordPress theme and agent plugin together.
- You expect non-developers to edit content.

Start with [SiteBay WordPress Theme And Agent Plugin](/docs/themes/wordpress/).

## Use Shopify When

- The site is primarily a storefront.
- Products, carts, checkout, and Shopify admin are the center of the workflow.
- You want SiteBay styling with Shopify theme settings.

Start with [SiteBay Shopify Theme](/docs/themes/shopify/).

## Use The Static Template When

- You need a simple marketing site or landing page.
- The site can be deployed to static hosting.
- You want a small, fast template without a CMS.

Start with [SiteBay Static Template](/docs/themes/static/).

## Ask Sorti

Prefer to decide by voice? Open [Sorti](/docs/sorti/) and describe the site you want to build.
