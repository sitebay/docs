Sorti is the SiteBay workspace for talking with an assistant and inspecting the work it performs. A session can contain a site canvas, panels, files, artifacts, and task progress.

## Use the right surface

Use the conversation to describe the result you need. Select an element on the canvas when the request concerns a specific part of a page. Open a panel when you need to inspect data or repeat a focused action.

The available tools depend on the connected services, site, credentials, and permissions. A visible integration does not by itself authorize every operation.

## Review changes

Check the site and environment before approving a mutation. For larger work, agree on scope and inspect the plan, changes, and verification evidence. A progress message is not proof that a deployment or external operation completed.

## Extend the workspace

First-party panels and connected MCP applications expose tools and UI resources. An external application retains its own data and permissions while Sorti provides the host workspace.

Read [How Sorti works]({{< relref "sorti/how-sorti-works.md" >}}) for the session model, or [Canvas and workspace]({{< relref "sorti/canvas-and-workspace.md" >}}) to start editing.
