This historical route is retained for existing bookmarks. The current reference is [Live-site API]({{< relref "api/site_live.md" >}}).

Use the methods and paths in the linked reference. The SiteBay API prefix is `/f/api/v1`; an article slug is not an API route. Authenticate as the correct account and verify the resource belongs to the selected team before submitting a change.

For support, redact credentials and identify the affected site, time, and operation. For site changes, inspect the current legal actions and wait for the operation result. An HTTP success for request submission is not equivalent to a completed repair.
