Depending on where you live, we might have to collect taxes by law. If you're in one of those spots, we'll automatically add the required tax rate to your bill for any taxable Kubernetes or WordPress services you're running.

{{< note >}}
The prices listed on our [Pricing](https://www.sitebay.org/pricing/) page and in the SiteBay dashboard don't include taxes. 
{{< /note >}}

## Where We Collect Taxes

Here's the current breakdown of where we collect taxes and how much. Keep in mind that tax rates can change, but your invoice will always reflect the most current rate.

| Country | Tax Rate | What it is | When we started |
| -- | -- | -- | -- |
| [Canada](#canada) (see below) | | | |
| United Kingdom | 20% | [VAT](https://www.gov.uk/vat-rates) | July 1, 2024 |
| United States | 0% | | | |

| Province | Total Tax Rate | Breakdown |

| British Columbia | 12% | 5% GST + 7% PST |

| New Brunswick | 15% | 15% HST |

| Northwest Territories | 5% | 5% GST |
| Nova Scotia | 15% | 15% HST |
| Nunavut | 5% | 5% GST |
| Ontario | 13% | 13% HST |
| Prince Edward Island | 15% | 15% HST |
