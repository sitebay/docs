The current [plan catalog]({{< relref "guides/quick-answers/sitebay-essentials/sitebay-plans/index.md" >}}) is authoritative for plan names, price fields and allowances. Prices are minor units and must be paired with the selected currency and billing interval.

Check the selected team's applied plan, actual usage and code-server eligibility before changing capacity. The earlier copied table contained contradictory prices and unverified sleep/recording rules; it has been removed rather than presented as a current quote. A catalog label does not prove that an editor is running or that a subscription change has completed.
