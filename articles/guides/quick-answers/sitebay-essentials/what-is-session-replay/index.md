# Session Replay

Watch recordings of real user sessions. See clicks, scrolls, mouse movements.

## Use Cases

| Problem | How Replay Helps |
|---------|------------------|
| Confusing UI | See where users struggle |
| Form drop-off | Watch where they quit |
| Bug reports | Reproduce exact issue |
| Conversion issues | Trace failed purchases |

## Privacy

- Sensitive inputs auto-masked
- Passwords hidden
- Credit cards hidden
- GDPR compliant

## Access

**Dashboard > Analytics > Recordings**

## Tips

- Filter by page URL
- Filter by user cohort
- Look for rage clicks (repeated clicking)
