## What to Skip

These are free anyway or don't add meaningful value over free alternatives:

- **GitHub Desktop** — Free already. Use the CLI or VS Code's built-in git.
- **GitHub Pages** — Free for public repos already. No special student value.
- **VS Code Coding Packs** — VS Code is free. The packs just install extensions.
- **Octicons / Template Collections** — Marginally useful, not significant.
- **InterviewCake** — Only 1 week. Barely enough time to get started.
- **Scrimba** — Only 1 month. Better free options exist for most learners.
