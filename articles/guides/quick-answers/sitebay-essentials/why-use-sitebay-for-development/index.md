# SiteBay for Development

WordPress development environment with built-in tools.

## Dev Features

| Feature | Benefit |
|---------|---------|
| **Code Server** | VS Code in browser |
| **WP-CLI** | Command-line WordPress |
| **Git Sync** | Version control |
| **Staging** | Test before deploy |
| **IntelliSense** | PHP + WP autocomplete |

## Why Use It

- No local setup needed
- Access from anywhere
- Team collaboration built-in
- Staging sites included
- Kubernetes scaling

## Workflow

1. Create staging site
2. Edit in Code Server
3. Test changes
4. Push to production
