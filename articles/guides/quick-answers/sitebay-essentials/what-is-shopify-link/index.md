# Shopify Link

Host WordPress blog on your Shopify store at `/a/blog`.

## Benefits

| Benefit | Why |
|---------|-----|
| SEO boost | Blog content on your domain |
| Unified brand | Same domain for store + blog |
| More traffic | Blog drives store visits |

## Setup

1. Install [SiteBay Shopify app](https://apps.shopify.com/wordpress-seo-blog)
2. Enable in theme settings
3. Configure at my.sitebay.org

See [Shopify Link Get Started](/products/shopify-link/get-started/) for full guide.
