Access your site's shell from the browser.

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `↓` / `j` / `e` | Scroll down |
| `↑` / `k` / `y` | Scroll up |
| `Space` | Page down |
| `b` | Page up |
| `g` | Jump to start |
| `G` | Jump to end |
| `10g` | Go to line 10 |
| `50%` | Jump to 50% |
| `/term` | Search forward |
| `?term` | Search backward |
| `n` | Next match |
| `N` | Previous match |
| `q` | Quit |

## Markers

| Key | Action |
|-----|--------|
| `m<c>` | Mark position with character |
| `'<c>` | Return to mark |
