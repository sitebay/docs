# Dashboard Overview

Manage all WordPress sites from one place.

## Main Sections

| Section | Purpose |
|---------|---------|
| **My Sites** | List of all sites, click to manage |
| **Analytics** | PostHog traffic and behavior data |
| **Monitoring** | Grafana performance dashboards |
| **Settings** | Account, billing, API access |

## Per-Site Features

- **WordPress Admin** — One-click access
- **Code Server** — VS Code in browser
- **Staging** — Test changes safely
- **PIT Machine** — Point-in-time restore
- **Recordings** — Session replay

## Quick Actions

- Create site: Sidebar → **Create Site**
- View analytics: Site → **Analytics** tab
- Clear cache: Site → **Tools** → **Clear Cache**
