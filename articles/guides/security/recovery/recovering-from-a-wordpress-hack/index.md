Restore your site to a pre-hack state using SiteBay's PIT Machine.

## Recovery Steps

1. Log into SiteBay dashboard
2. Go to **PIT Machine** tab
3. Select date/time before the hack
4. Click **Restore**
5. Verify site is working

## After Recovery

- Change all passwords
- Update WordPress core, plugins, themes
- Install security plugin (Wordfence)
- Enable 2FA
- Review user accounts for suspicious additions
- Check for modified files

## Prevention

- Keep everything updated
- Use strong passwords
- Limit login attempts
- Regular backups
- Monitor for suspicious activity
