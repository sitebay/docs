Monitor your WordPress site's traffic and security.

## What You Can Track

| Data | Purpose |
|------|---------|
| Visitor IPs | Geographic insights, block bad actors |
| HTTP responses | Detect errors (404, 500) |
| User agents | Browser/device breakdown |
| Referers | Traffic sources |

## Access Logs

SiteBay dashboard → Logs section

## Use Cases

- **Performance**: Find slow pages
- **Security**: Detect failed login attempts
- **Traffic**: Understand visitor patterns
- **Debugging**: Trace errors

## Tools

- SiteBay dashboard logs
- PostHog session recordings
- Grafana dashboards
- Wordfence live traffic
