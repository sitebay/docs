SiteBay separates the resources you manage so a change can target the correct thing.

| Resource | Purpose |
| --- | --- |
| Account | Your identity and authentication |
| Team | Membership, access, and billing context |
| Live site | The hosted site and its current status |
| Staging site | A separate environment for reviewing changes |
| Git connection | Repository-backed code deployment |
| Recovery point | An available state for inspection or restoration |
| Sorti session | A shared workspace with an assistant |

Select the team, site, and environment before making a change. Creating a staging site does not publish it; deleting a site and cancelling a subscription are also different operations.

Start with [Site lifecycle]({{< relref "products/platform/site-lifecycle/index.md" >}}) and [Teams and billing]({{< relref "products/platform/teams-and-billing/index.md" >}}).
