Compare the cost of an actual workload, not only the advertised price of one server.

## Describe the workload

Record expected traffic, storage, database size, background work, regions, recovery needs, and support requirements. Separate development usage from production usage.

## Build a complete estimate

Include compute, managed databases, storage, requests, transfer, backups, logging, support, taxes, and third-party subscriptions where applicable. Compare equivalent availability and recovery requirements.

A managed WordPress plan and a bare virtual machine include different responsibilities. Account for the work needed to maintain the application and infrastructure.

## Test the assumptions

Run a bounded test and compare measured usage with the estimate. Check peak demand as well as the quiet period. Review service-specific billing units and minimum commitments in the provider's current pricing material.

## Apply discounts last

Show the normal cost separately from trial credits, promotional awards, or committed-use discounts. Record expiry dates and commitments so the project remains viable when the discount ends.
