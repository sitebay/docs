Use an assistant to help define a question and inspect the available analytics data. State the project, site, time range, and outcome you want to understand.

## Use it

Review the query, filters, and underlying records before accepting an interpretation. Ask for a draft before allowing changes to a dashboard or project setting. An assistant answer is not proof that a query or write completed.
