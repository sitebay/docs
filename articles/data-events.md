# Website Events

Events are actions users take: clicks, page views, form submissions, downloads, purchases.

## Auto-Tracked Events

Sitebay automatically captures:
- Page views
- Button/link clicks
- Form submissions
- File downloads
- External link clicks
- Cart actions (add/remove)
- Errors (404s, failed submissions)

## Event Types

| Event | Business Use |
|-------|-------------|
| Page view | Content popularity |
| Button click | CTA effectiveness |
| Form start/complete | Conversion funnel |
| Add to cart | Shopping intent |
| Purchase | Revenue tracking |
| Video play | Content engagement |

## Funnels

Track drop-off through conversion paths:

```
Homepage (1000) → Product (400) → Add Cart (120) → Checkout (80) → Purchase (50)
```

Drop-off at each step tells you where to optimize.

## Using Event Data

**Weekly check (15 min)**:
1. Top pages
2. Most clicked elements
3. Form completion rates
4. Drop-off points

**Monthly analysis (1 hr)**:
1. Funnel performance
2. Mobile vs desktop differences
3. Traffic source behavior
4. Content effectiveness

## Custom Events

For specific tracking needs:
1. **Dashboard > Events > Create Custom**
2. Define trigger (element click, URL visit, etc.)
3. Name clearly: `newsletter-signup`, `pricing-page-cta`
4. Test before relying on data

## Common Patterns

| Pattern | Insight | Action |
|---------|---------|--------|
| High form starts, low completes | Form too long/complex | Simplify |
| Clicks on non-clickable elements | Looks interactive | Make clickable or restyle |
| Mobile drops off earlier | Mobile UX issues | Test on devices |
| Video watchers convert more | Video builds trust | Add more videos |
