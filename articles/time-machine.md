# Time Machine

Time Machine helps you inspect recent WordPress file and database changes before starting a restore.

## What You Can Do

- Review recent restore points for a site
- Browse files from a selected point in time
- Compare recent database and file activity by day
- Restore a single file or start a full file restore

## When To Use It

Use Time Machine when a plugin update, theme edit, upload, or content change breaks a site and you need to find the last known good state.

## Before Restoring

Check the selected date and affected files carefully. A restore changes live site content, so confirm the restore point matches the incident you are trying to recover from.

## Git-Managed Sites

Sites managed by Git may show commit history instead of point-in-time file browsing. In that case, select a file to review its recent commits and restore from source history.
